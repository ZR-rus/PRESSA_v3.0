Это исходный код программы для Windows на C++ (Win32 API) — приложение для сбора и регистрации данных с промышленных прессов через COM-порты.
Приложение принимает данные от контроллеров (ATmega) на прессах, отображает состояние 16 (или 12) входов/датчиков и ведёт журнал в Excel-совместимые файлы (.xls).
